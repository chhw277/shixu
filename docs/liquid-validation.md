# 1.1.2 验证记录

日期：2026-11-11（Asia/Shanghai）。基线：1.1.1；当前版本：1.1.2。

## 本地已执行

- 新增 TypeScript 动画/音效模块、受控按钮及调用示例的类型检查通过。
- 38 项原有业务/真实文件存储测试通过。
- 9 项音效、几何和主题首屏测试通过，覆盖阶段去重、零音量、静音、中断、卸载、解锁失败、减少动态效果、主题恢复、不同视口路径及真实离线 Web Audio 输出。
- 两个方向的音效从实际 LiquidAudio 模块各离线生成 3.05 秒 WAV，默认 28% 音量 RMS 约 0.0086，峰值 0.1724/0.1768；另验证 100% 音量无数字削波。数字电平检查不等于所有音响设备的真人听感检查。
- Vite 生产构建、源码差异格式检查通过。
- Mac 应用已进行 ASAR 文件逐项一致性检查及 codesign 深度严格签名校验；确认包内没有顶部声音按钮，设置内开关/音量/试听仍在，快速添加输入的内部焦点框已移除、外侧提示保留。

## 平台发布门槛

Windows Actions 执行类型检查、38 项业务测试、9 项主题/音效测试、26 项浏览器界面用例、打包程序 smoke、安装包生成、安装后启动/重启/导入导出、卸载后数据保留。

Mac 发布任务只接受同一成功 Windows 提交，重新构建相同源码、执行模型/音效检查、运行打包应用 smoke、校验 ASAR 与源码，然后上传三种安装/便携文件及 SHA-256。实际任务结果与报告在该版本对应的 GitHub Actions 中查看，失败任务不会发布。

浏览器用例涵盖双向切换、390/768/1380 像素布局、滚动与 sticky/fixed 对齐、表单状态、ID 引用、重复操作、中断、卸载、音效选择记忆及降级。打包应用测试补充检查双向主题切换、快速输入仅保留外侧焦点、顶部声音按钮缺失。

本机的浏览器/桌面观察工具曾受权限策略限制，本地没有据此声称交互实测通过；平台界面检查在隔离的 CI 运行，不访问本机日常数据。

## 已知限制

视觉副本在动画期间冻结自动变化内容；真实业务继续运行，用户编辑/滚动会先结束动画。Canvas/WebGL/视频/iframe/开放 Shadow DOM 自动直接切换；封闭 Shadow DOM、跨文档 top-layer 不在复制支持范围。Safari/iOS、全部旧 WebView 与低端设备未完整实机验收。完整支持范围见 liquid-theme.md。
