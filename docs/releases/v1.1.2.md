## 本次更新

- 浅色和深色主题可通过液柱、液滴、飞溅及上涨波浪逐步切换，保留页面内容、表单和业务状态。
- 配套水声由本机合成，与实际动画阶段同步；调整合成电平，解决初版声音过轻的问题。
- **声音默认关闭，在“设置 → 切换音效”开启、调节音量或试听。** 顶部不再放置声音按钮。
- 修复快速添加任务栏里多余的矩形蓝框，仅保留添加栏外侧的焦点提示。
- 增加手机/平板窄屏样式、主题刷新恢复、动态跟随系统及异常中断清理。
- 以上修改同步包含在 Windows 安装版、Windows 免安装版、macOS 版及共享网页源码中。

完整记录见 [CHANGELOG.md](https://github.com/chhw277/shixu/blob/v1.1.2/CHANGELOG.md)。

## 更新方式

先正常退出旧版，再安装 Windows EXE，或解压并打开新版 Mac/Windows 应用。任务保存目录和 JSON 格式保持兼容，安装包不包含个人任务数据。Windows 免安装包须完整解压，不能只复制 EXE。

Windows 安装版会更新当前用户的程序文件，卸载仍保留任务数据。Mac 最低 macOS 13，适用于 Apple Silicon；Windows 适用于 Windows 10/11 x64。现有发布范围不包含 Linux、Android、iOS、Intel Mac 或 Windows ARM 专用包。

## 验证与限制

发布流程先执行类型检查、38 项业务/存储测试、9 项音效/几何/首屏测试及 26 项浏览器界面用例，再验证 Windows 打包程序、安装后启动、重启、导入导出、卸载保留数据；macOS 包独立构建并进行打包程序测试与完整性校验。

Canvas/WebGL、视频、iframe 和开放 Shadow DOM 页面使用直接切换；视觉副本在切换期间短暂冻结自动变化内容。音频播放受系统输出、静音和设备音量影响。Safari/iOS 与所有低端设备尚未做完整实机验收。

Windows 应用尚无商业代码签名证书，macOS 包使用 ad-hoc 签名，未做 Apple 开发者公证。当前没有客户端自动升级、云同步或独立账号；下载后需手动安装新版。仓库为私有时下载需有相应访问权限。
