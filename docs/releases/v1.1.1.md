## 本次更新

- Windows 提供安装程序和免安装 ZIP，使用系统标题栏与 Ctrl 快捷键。
- 任务、习惯、专注、废纸篓、批量操作及连续输入与 macOS 版保持一致。
- Windows 数据位于 `%APPDATA%\拾序\data`；更新或卸载程序保留用户数据。
- GitHub Actions 验证领域逻辑、Windows 磁盘保存、实际启动、退出重启、导入导出，以及安装后运行和卸载保留数据。

Windows 安装版：下载 `Shixu-1.1.1-Windows-x64-Setup.exe`。免安装版：完整解压 `Shixu-1.1.1-Windows-x64.zip`，运行其中的 `Shixu.exe`，不要只复制 EXE。

macOS：下载 `Shixu-1.1.1-macOS-arm64.zip`，解压后打开拾序.app，最低 macOS 13。

当前版本为本地应用。Supabase 云同步、账号登录、安卓客户端和客户端自动升级尚未实现；GitHub 发布新版安装包不会自动更新已安装的客户端。Windows 包未购买代码签名证书，macOS 包仅有本机 ad-hoc 签名，未做 Apple 公证。

请使用同一 Release 中的 SHA256SUMS.txt 核对下载文件。仓库和 Release 为私有时，需要仓库访问权限才能下载。
