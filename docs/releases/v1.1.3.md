## 本次更新

- 备忘录支持新增、随输入保存、搜索、确认删除，内容包含在 JSON 备份中。
- 旧版任务数据和旧备份缺少 memos 字段时自动补空列表，保留原有任务、清单、习惯、专注历史和设置；非法数据仍拒绝导入。
- 列表、看板和四象限的快速专注统一保护已有运行、暂停或休息计时；不会覆盖正在进行的计时。
- 修复刚开始就暂停时剩余秒数偶尔超过总时长，导致重启后计时失效的问题。
- 今日全部完成波纹和统计数字动效接入真实变化，习惯动画只在点击完成时触发，并遵循系统减少动态效果设置。
- 修复备忘录切页前未失焦内容保存、搜索中新增、页面恢复和 JSX 运行时导入问题。

## 更新与验证

退出旧版后再安装或打开新版。任务数据仍保存在本机，更新不要求清空数据；首次使用备忘录后，新数据格式向前兼容读取旧备份，回退旧应用时请使用更新前备份。

本机通过 45 项业务/存储测试、9 项主题/音效逻辑测试及 36 项浏览器界面测试；最终 macOS 应用完成签名、启动、保存、退出重启、导入导出和真实数据隔离副本验证。发布前另由 GitHub Actions 验证 Windows 打包程序、安装/卸载及 macOS 最终包的相同行为。

Mac 适用于 macOS 13+ Apple Silicon；Windows 适用于 Windows 10/11 x64。Windows 免安装版需要完整解压，不能单独复制 EXE。Mac 包使用本机临时签名，未做 Apple 公证；Windows 包未购买商业代码签名证书。

当前仍为本地应用，账号、云同步、安卓和客户端自动升级尚未实现。
